## L'outil qui simplifie ta gestion et ta journée d'architecte.

Kairos est une application de gestion conçue **spécifiquement pour les architectes et cabinets d'architecture**. Projets, communications, équipe, agenda : tout au même endroit.

## Tout ce dont votre agence a besoin

{{< features >}}
{{< feature icon="fa-gauge-high" title="Dashboard complet" >}}
Toutes les infos importantes en un seul coup d'œil. Tâches, échéances, projets en cours, météo d'équipe : rien ne vous échappe.
{{< /feature >}}

{{< feature icon="fa-folder-open" title="Gestion de projets" >}}
Suivi par phases clair et structuré. Chaque projet regroupe toutes ses infos, échanges et documents. L'équipe suit l'avancement en temps réel.
{{< /feature >}}

{{< feature icon="fa-envelope" title="Communications centralisées" >}}
Gérez vos mails directement dans Kairos. Reliez-les à un projet, partagez-les ou taguez-les pour mieux trier. Messagerie interne incluse.
{{< /feature >}}

{{< feature icon="fa-calendar" title="Agenda partagé" >}}
Un calendrier commun pour toute l'agence. Visualisez tous les événements qui vous concernent, synchronisé avec Google Calendar.
{{< /feature >}}
