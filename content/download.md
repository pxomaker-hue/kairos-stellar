# Télécharger Kairos

Kairos est disponible en **Progressive Web App (PWA)** — aucune installation requise depuis un store.  
Accédez à l'application directement depuis votre navigateur et installez-la en un clic sur votre appareil.

## Comment installer Kairos ?

### Sur ordinateur (Chrome / Edge)

1. Rendez-vous sur **[kairos-archi.vercel.app](https://kairos-archi.vercel.app)**
2. Cliquez sur l'icône **"Installer"** dans la barre d'adresse (icône ⊕)
3. Confirmez l'installation

### Sur mobile (Android)

1. Ouvrez Chrome et allez sur **[kairos-archi.vercel.app](https://kairos-archi.vercel.app)**
2. Appuyez sur le menu **⋮** puis **"Ajouter à l'écran d'accueil"**
3. L'icône Kairos apparaît sur votre écran

### Sur mobile (iOS / Safari)

1. Ouvrez Safari et allez sur **[kairos-archi.vercel.app](https://kairos-archi.vercel.app)**
2. Appuyez sur **Partager** puis **"Sur l'écran d'accueil"**
3. Confirmez
